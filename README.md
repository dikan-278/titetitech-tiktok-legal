# Tí Te Tí Tech Dashboard — TikTok integration

Private, single-user analytics tool built and operated by the owner of the TikTok account [@tite_titech](https://www.tiktok.com/@tite_titech).

## What this app does
After the account owner signs in through TikTok Login Kit and grants consent, the app reads the owner's own public TikTok videos and their public counters (views, likes, comments, shares) via the TikTok Display API (`video.list`), and displays them in a local, private dashboard used only by the owner to track the performance of their own content over time.

This app does not post, edit, or delete content on TikTok, and does not access any account other than the owner's own.
